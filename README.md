# 📡 رادار الجولة — Telegram FPL Radar

بوت عربي مستقل لتحليل Fantasy Premier League ومساعدة مستخدم اللعبة المجانية. الأسعار المعروضة تخص ميزانية اللعبة الافتراضية.

## ما تم إنجازه

- جلب بيانات اللاعبين والأسعار والمباريات من FPL وتخزين مؤقت لمدة خمس دقائق.
- ثلاثة مرشحين لكل مركز، مع السعر والنادي والخصم والصعوبة والفورمة والملكية وحصة الدقائق وسبب الترشيح.
- مرشحو الكابتن، خيارات اقتصادية، لاعبون بملكية أقل من 10%، فلترة بالمركز والسعر.
- نظرة إلى المباريات خلال ثلاث جولات، ومعالجة الجولات المزدوجة والخالية.
- صورة PNG عربية تولد برمجيًا من التقرير نفسه؛ لا تحتاج خدمة توليد صور أو اشتراك AI.
- تنبيهات مرتبطة بموعد الجولة الفعلي: قبل الإغلاق بـ24 ساعة، ثم ساعة، بعد `/subscribe`.
- قاعدة SQLite تحفظ الاشتراكات وتمنع تكرار التنبيه في التشغيل المعتاد، وتحفظ آخر تقرير مولد لكل جولة.
- أزرار تيليجرام وأوامر عربية، إيقاف الاشتراك وحذفه، تقييد اختياري بمعرّفات المستخدمين.
- Docker مع إعادة تشغيل تلقائية ووحدة تخزين دائمة؛ لا يحتاج دومين أو منفذ عام.

## الحالة الحالية

حساب البوت: https://t.me/RadaratiBot

هذه النسخة مجهّزة للنشر على Railway من هذا المستودع. نجاح البناء وحده لا يعني أن البوت يعمل: يجب إضافة `TELEGRAM_BOT_TOKEN` كمتغير سري، وإرفاق وحدة تخزين دائمة على `/app/data`، والتحقق من سجل `Bot running`. لا تضف التوكن أو قاعدة البيانات إلى المستودع.

نجحت 12 حالة اختبار محلية، واختُبر جلب بيانات FPL وإنتاج بطاقة عربية. يمكن توليد نماذج جديدة عبر `python bot.py --preview`.

## التشغيل السريع عبر Docker

1. افتح الحساب الرسمي [BotFather](https://t.me/BotFather) في تيليجرام، وأرسل `/newbot`، ثم اختر اسمًا واسم مستخدم ينتهي بـ`bot`. احتفظ بالتوكن كسر ولا تضعه في GitHub أو ترسله في المحادثة.
2. فك ضغط المشروع على جهاز أو خادم عليه Docker Compose، وافتح الطرفية داخل المجلد.
3. انسخ `.env.example` إلى `.env`:

```bash
cp .env.example .env
```

على PowerShell:

```powershell
Copy-Item .env.example .env
```

4. حرر `.env` محليًا وضع التوكن مكان `replace_me` في `TELEGRAM_BOT_TOKEN`.
5. شغّل:

```bash
docker compose up -d --build
docker compose logs --tail 50
```

6. افتح رابط البوت الذي أعطاك إياه BotFather واضغط Start، ثم `/gw` و`/card`. أرسل `/subscribe` لتفعيل الإشعارات.

اترك الجهاز والخدمة متصلين بالإنترنت طوال الوقت. للإيقاف: `docker compose down`؛ تجنب إضافة `-v` حتى لا تحذف قاعدة البيانات. شغّل نسخة واحدة فقط لكل توكن. عند وجود Webhook سابق، يرفض التشغيل بدل حذف إعدادك تلقائيًا؛ أوقف Webhook القديم أولًا عبر Telegram API.

## تشغيل مباشر على Linux / Windows

Python 3.12 أو أحدث، ثم:

```bash
python -m venv .venv
```

تفعيل البيئة على Linux: `source .venv/bin/activate`، وعلى Windows: `.venv\Scripts\Activate.ps1`.

```bash
pip install -r requirements.txt
python bot.py
```

في Windows عدّل `FONT_PATH` في `.env` إلى خط عربي مثبت، مثل `C:/Windows/Fonts/arial.ttf`. في Linux ثبّت `fonts-dejavu-core` و`libraqm0` إن لزم؛ Docker يثبتهما. توليد العربية يحتاج Pillow مع RAQM. النسخة الأساسية من Python تستخدم المكتبة القياسية للاتصالات وقاعدة البيانات؛ Pillow للصور وtzdata للمناطق الزمنية.

لتجربة تقرير وصورة دون توكن:

```bash
python bot.py --preview
```

## الأوامر

| الأمر | النتيجة |
|---|---|
| `/gw` | تقرير أول جولة لم تغلق |
| `/gw 6` | تحليل الجولة 6 إن كانت مستقبلية |
| `/picks MID 7.5` | أفضل أربعة لاعبي وسط بسعر حتى 7.5 |
| `/picks GK 5` | حراس حتى 5؛ المراكز الأخرى DEF وFWD |
| `/captain` | مرشحو الكابتن |
| `/budget` | أفضل قيمة بسقوف أسعار حسب المركز |
| `/differentials` | خيارات ملكيتها أقل من 10% |
| `/fixtures` | مباريات أبرز المرشحين خلال ثلاث جولات |
| `/card` | بطاقة إنفوجرافيك قابلة للمشاركة |
| `/subscribe` | تفعيل تقارير ما قبل الإغلاق |
| `/stop` | إيقاف التقارير التلقائية |
| `/history` | آخر تقرير محفوظ؛ ليس تحليلًا تاريخيًا مُعادًا |
| `/method` | شرح المؤشر وحدوده |
| `/delete` | حذف الاشتراك وسجل التنبيهات |

## كيف يحلل؟

مؤشر إرشادي شفاف؛ ليس نموذج تعلم آلي مدرّبًا ولا توقع نقاط معايرًا:

| المكوّن | الوزن | الحساب |
|---|---:|---|
| الفورمة | 32 | form / 10، بسقف 1 |
| نقاط المباراة | 22 | points_per_game / 8، بسقف 1 |
| حصة الدقائق الموسمية | 18 | minutes / (90 × مباريات النادي المنتهية)، بسقف 1 |
| مباريات الجولة | 18 | مجموع (6 − FDR) / 5 لكل مباراة |
| المؤشرات الأساسية | 10 | للهجوم والوسط xGI/90؛ للدفاع والحراس xGC/90 مع المساهمة الهجومية |

تُضرب النتيجة في نسبة الإتاحة المنشورة؛ إن كانت غير محددة تُعامل كـ100% في الحساب وتُعرض «غير محددة». السقف النهائي 100. ترتيب الكابتن يشترط حالة متاح وحصة دقائق 65% على الأقل؛ لا يضمن بدء المباراة. ثقة المؤشر محدودة قبل خمس مباريات أو مع انخفاض الدقائق. مكوّن الدقائق تقريبي وقد يتأثر بمباراة جارية وانتقال اللاعب بين الأندية.

الإصابة والإيقاف وعدم الإتاحة، فرصة مشاركة أقل من 75%، صفر دقائق، أو غياب مباراة مجدولة يستبعد اللاعب. هذا يُفوّت أحيانًا لاعبين جددًا واعدين. تحليل الجولات الأبعد يستعمل الحالة والأداء الحاليين، وليس توقع الإصابات أو التشكيل المستقبلي. الأسابيع المزدوجة تضيف فرصة المباراة؛ المباريات المؤجلة دون جولة لا تدخل إلى أن يحددها المصدر.

خيارات الاقتصاد مرتبة بالمؤشر/السعر، بسقوف 5 للحارس والمدافع، 6.5 للوسط، 7 للهجوم، وحصة دقائق ≥60%. قائمة قليلة الملكية تستخدم سقف 10% وحصة دقائق ≥60%.

هذه **قوائم ترشيح مستقلة وليست تشكيلة كاملة** ملتزمة بميزانية 100 أو ثلاثة لاعبين من النادي. لا يدخل البوت حساب FPL، ولا ينفذ انتقالات، ولا يحلل فريق المستخدم أو يقدم تقييمًا رجعيًا للأداء في هذه النسخة.

## الاعتمادية والبيانات

- الخاص فقط؛ البوت لا يشترك نيابة عن مجموعات. لا رسائل تلقائية إلا بعد `/subscribe`.
- تخزين معرّف المحادثة ووقت الاشتراك وسجل التنبيهات وموضع التحديثات؛ لا كلمات مرور FPL.
- التوكن داخل `.env` المستبعد من Git وDocker build؛ لا تسجل عناوين الطلبات التي تتضمن التوكن.
- عند تعطل مصدر البيانات، لا تُعرض النسخة القديمة كتقرير حديث. `/history` معنونة صراحة كتقرير محفوظ.
- التنبيه يعمل داخل نافذة 24 ساعة ثم نافذة ساعة. إذا بدأ البوت متأخرًا يصل تنبيه النافذة الحالية؛ لا يعيد تنبيه 24 ساعة داخل الساعة الأخيرة، ولا يرسل بعد الإغلاق. تغير الموعد يستخدم الموعد الأحدث.
- الإرسال عمليًا at-least-once: تعطل العملية بين تسليم Telegram وتسجيل نجاح الإرسال قد يكرر الرسالة. فشل جزء من تقرير متعدد الرسائل قد يكرر الأجزاء السابقة عند المحاولة التالية.
- يحتفظ الأرشيف بآخر تقرير مولد لكل جولة وليس جميع الإصدارات. لا يتوفر تحليل تاريخي لجولة لم تُحفظ من قبل.
- تحتاج الخدمة خروج HTTPS إلى `fantasy.premierleague.com` و`api.telegram.org`. واجهة FPL العامة غير مضمونة الثبات وقد تحتاج صيانة عند تغير الحقول.
- Docker يعمل بمستخدم غير root؛ انسخ وحدة `radar-data` احتياطيًا دوريًا. لا توجد لوحة مراقبة أو ضمان تشغيل مُدار مرفق.

## التحقق

```bash
python -m unittest discover -s tests -v
python bot.py --preview
```

الاختبارات تغطي الأسعار والفلترة والإصابات والجولة المزدوجة والخالية ورفض التحليل بأثر رجعي وحدود التنبيهات واستمرار الحالة ومنع التكرار العادي وتقسيم رسائل Unicode ورفض البيانات القديمة. بعد وضع التوكن اختبر يدويًا `/start` و`/gw` و`/card` و`/subscribe` و`/stop`، ثم أعد تشغيل الحاوية وتحقق من استمرار الاشتراك.
